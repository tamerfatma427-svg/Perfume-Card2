# Perfume Card 2

A responsive product card for a perfume, built with plain HTML and CSS. The design is a navy and gold take on a classic product card layout.

![Preview](./preview.png)

## Features

- Product image on the left, details on the right
- Category label, product name and short description
- Current price with the old price crossed out
- "Add to Cart" button with a hover effect
- Card centered on the page using Flexbox

## Built With

- HTML5
- CSS3 (Flexbox)
